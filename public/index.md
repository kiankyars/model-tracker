# Model releases

Language model releases and verified announcements by date, developer, type, and parameter count. View release counts, cumulative releases, developer comparisons, and model sizes. Download filtered records as CSV or JSON.

- [API documentation](https://kiankyars.github.io/model-tracker/api.md)
- [Coverage and methodology](https://kiankyars.github.io/model-tracker/about.md)
- [Agent entry point](https://kiankyars.github.io/model-tracker/llms.txt)
- [GitHub repository](https://github.com/kiankyars/model-tracker)

The catalog includes source links and uses null for missing fields. Charts count recorded releases; announcements remain visible in the catalog. Coverage is incomplete. [Historical audit coverage](./api/v1/coverage.json) records source review by month.
