# Model releases

An open timeline of language model releases, covering open-weight and closed models. Filter by release month, developer, type, and parameter count; explore monthly statistics; download filtered results as CSV or JSON.

- [Explore the website](https://kiankyars.github.io/model-tracker/)
- [Full dataset](https://kiankyars.github.io/model-tracker/api/v1/models.json)
- [API discovery](https://kiankyars.github.io/model-tracker/api/v1/index.json)
- [API documentation](https://kiankyars.github.io/model-tracker/api.md)
- [Coverage and methodology](https://kiankyars.github.io/model-tracker/about.md)
- [Agent entry point](https://kiankyars.github.io/model-tracker/llms.txt)
- [GitHub repository](https://github.com/kiankyars/model-tracker)

Coverage is broad but incomplete. Statistics describe catalogued releases. Source links accompany every model, unknown fields remain null, and open weights should not be interpreted as an open-source license claim. Read the methodology before drawing conclusions about release trends.
